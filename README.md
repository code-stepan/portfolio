# ⚡ Персональный сайт-портфолио Степана

Современный, адаптивный и интерактивный сайт-портфолио разработчика с поддержкой **GitHub Pages**, переключением тем (тёмная/светлая), мультиязычностью (RU/EN), фильтрацией проектов, интерактивным фоном (Canvas) и анимациями.

---

## 🚀 Как опубликовать на GitHub Pages (за 1 минуту)

Поскольку сайт написан на чистом стеке (HTML5 + CSS3 + ES6+ JavaScript), для него **не требуется сборка** (Zero-Build). Он работает прямо «из коробки» на GitHub Pages!

### Шаги для публикации:

1. **Закоммитьте и отправьте файлы в репозиторий GitHub:**
   ```bash
   git add .
   git commit -m "feat: complete modern portfolio website"
   git push origin main
   ```
   *(если ваша ветка называется `master`, замените `main` на `master`)*

2. **Включите GitHub Pages в настройках репозитория:**
   - Перейдите в ваш репозиторий на GitHub: `https://github.com/code-stepan/portfolio`
   - Нажмите вкладку **Settings** (Настройки) вверху.
   - В левом боковом меню выберите раздел **Pages** (под разделом *Code and automation*).
   - В блоке **Build and deployment**:
     - В выпадающем списке **Source** выберите **Deploy from a branch**.
     - В **Branch** выберите ветку `main` (или `master`) и папку `/(root)`.
     - Нажмите **Save** (Сохранить).

3. **Готово!**
   Через 1–2 минуты GitHub Pages опубликует ваш сайт по адресу:
   👉 **`https://code-stepan.github.io/portfolio/`**

## 🛠️ Локальный запуск и просмотр

Вы можете просто дважды кликнуть по файлу `index.html`, чтобы открыть его в любом браузере.

Либо запустить локальный сервер для комфортной разработки:

**Через Python:**
```bash
python -m http.server 3000
```
После чего откройте `http://localhost:3000` в браузере.

**Через Node.js:**
```bash
npx serve
```

## ⚙️ Как кастомизировать информацию под себя

### 1. Контакты и ссылки на соцсети:
В файле `index.html`:
- Замените `https://t.me/your_telegram` на ваш реальный ник в Telegram.
- Замените `stepan.developer@example.com` на вашу почту (также в атрибуте `data-email="ваш-email"` у кнопки копирования).
- Проверьте ссылку на GitHub (`https://github.com/code-stepan`).

### 2. Проекты:
В секции `<section id="projects">` в `index.html` расположены карточки проектов:
- Вы можете менять название, стек технологий, описание и ссылки на демо (`href="..."`) и репозиторий проекта.
- У каждой карточки есть атрибут `data-category="fullstack"` (или `frontend`, `backend`), который используется для фильтрации.

### 3. Тексты и перевод (RU / EN):
В файле `js/main.js` в объекте `translations` собраны все текстовые фразы на русском (`ru`) и английском (`en`). Вы можете легко отредактировать биографию, опыт работы или добавить новые пункты.

## ✨ Особенности дизайна и функционала

- 🎨 **Современный UI**: Glassmorphism, акцентные градиенты, карточки с неоновым свечением.
- 🌓 **Переключение тем**: Тёмная (Dark) и Светлая (Light) тема с сохранением выбора в `localStorage` и поддержкой системных предпочтений.
- 🌐 **Двуязычность**: Мгновенное переключение RU / EN без перезагрузки страницы.
- 💻 **Интерактивное окно кода**: Стилизованный терминал с информацией о стеке в Hero-секции.
- 🔍 **Фильтрация проектов**: Переключение между категориями (Все / Full-Stack / Frontend / Backend).
- 📋 **Копирование Email в 1 клик**: С интерактивным всплывающим Toast-уведомлением.
- 📱 **100% Адаптивность**: Идеально отображается на смартфонах, планшетах и широкоформатных мониторах.
- 🚀 **Zero-Build**: Никаких `npm install` или сложных бандлеров — чистый, сверхбыстрый и долговечный код.
