Кредитный скоринг: прогнозирование дефолта заёмщика 2026
Pet-проект · GitHub
Python · Pandas · NumPy · scikit-learn · CatBoost · SHAP · FastAPI · Docker · SQL

Модель вероятности дефолта заёмщика на датасете Home Credit Default Risk (Kaggle, ~307 тыс. заявок, несколько таблиц с историей кредитов): бинарная классификация с несбалансированными классами.

  • Провёл EDA и feature engineering: финансовые ratio-признаки, агрегация истории внешних кредитов из Bureau, обработка пропусков и аномалий.
  • Сравнил интерпретируемую Logistic Regression + WOE и градиентный бустинг CatBoost на стратифицированной 5-fold CV и holdout-выборке: ROC-AUC 0.7737 (holdout) и 0.7686 (CV) у CatBoost против 0.7551 и 0.7508.
  • Оценил модель отраслевыми метриками: Gini 0.5473, KS 0.4096; рассчитал PSI между обучающей и holdout-выборками. Реализовал интерпретацию предсказаний через SHAP.
  • Разработал REST API на FastAPI (вероятность дефолта и скоринговое решение), подготовил Docker-конфигурацию и SQL-запрос для формирования витрины признаков.
Tourist RAG: русскоязычный помощник по достопримечательностям 2026
Pet-проект на основе задания DLS МФТИ · GitHub
Python · sentence-transformers · Chroma · Qwen2.5 · pytest

RAG по 355 достопримечательностям четырёх городов (описания из WikiData, подписи к фото BLIP, координаты).

  • Построил пайплайн: очистка выбросов (TF-IDF, правила, zero-shot по эмбеддингам), чанкинг с контекстными заголовками, эмбеддинги multilingual-e5 и векторный поиск в Chroma, BM25, слияние RRF, реранкинг cross-encoder, генерация ответа Qwen2.5. Оформил как пакет с CLI и тестами.
  • Сравнил 4 конфигурации поиска на 100 вопросах: MRR вырос с 0.560 (dense) до 0.675, Hit@3 — с 0.57 до 0.74. Выявил, что наивное слияние BM25 и dense (RRF) ухудшает поиск (MRR 0.419), а реранкер это компенсирует.
  • Реализовал метрики RAGAS без библиотеки ragas: answer relevancy 0.81, faithfulness 0.73, context precision 0.83, context recall 0.61. Для поиска использовал Hit@k и MRR.
